# 跨境账桥 · BorderLedger

跨境电商资金流转与税务合规研究工作台。

当前版本聚焦 **TikTok Shop 美国店铺 × 独立香港合作公司** 的资金链路、供货与运营服务模式、美国申报与香港利得税基础知识。

## 在线访问

https://templehao.github.io/borderledger/

## 包含功能

- 美区平台、美国公司与香港合作方之间的资金流向图
- 真实货物贸易、服务外包和代理模式的差异
- 美国 C-Corp 与香港公司的示意税务计算器
- 可在当前浏览器保存的合规材料清单
- IRS、香港税务局及 TikTok Shop 官方参考链接

## 发布

仓库 `main` 分支更新后，`.github/workflows/pages.yml` 自动上传静态文件到 GitHub Pages。首次请在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

网站采用纯静态 HTML/CSS/JavaScript，无后端或支付、收款、税务申报功能；清单仅存在浏览器本地存储中，不会传输到服务器。图标文件为 `favicon.svg`，网站 HTML 还内嵌 Favicon 和 Apple Touch Icon。

## 重要声明

内容仅用于业务与税务知识研究，计算器为简化模型，不构成美国或香港税务、法律、会计意见。实际税负取决于公司类型、税务居民身份、经营州、服务履行地点、贸易条款、抵免、应税利润调整等。请由持牌/合格税务专业人士复核。
